# Design direction

## Design Read

Reading this as: a personal GitHub archive for Zelda Ababil, for people checking their work, in a quiet index style, dial ENERGY 1 / RHYTHM 1 / MOTION 1.

## Identity

Zelda Ababil is presented as a builder who cares about mobile products and the structure underneath them. This is an inferred positioning from the public repository mix, not a claim of employment or seniority.

## Evidence

- Observed: the public GitHub profile names Zelda Ababil, lists Jember, and describes an Informatics Engineering background at Muhammadiyah University of Jember.
- Observed: public repositories include several Flutter and Dart projects, plus JavaScript, Python, PHP, Kotlin, HTML, and C++ projects.
- Observed: public project descriptions mention DDD, layered architecture, MVVM, Riverpod, Supabase, and a face-recognition API.

## Visual decisions

- An off-white background and restrained typography make the page read like a maintained archive, not a marketing landing page.
- Vermilion appears only for status, row numbering, and link emphasis so it acts as a reading cue rather than decoration.
- A serif display face paired with a system sans separates identity from repository metadata without loading external fonts.
- Repositories are shown as a plain indexed list because the evidence is the repositories themselves, not invented case-study framing.
- The page contains only profile context, public repositories, and a short source boundary. Testimonials, statistics, pricing, and filler sections are excluded.
- Motion is limited to hover and focus transitions. The content is the subject, so motion does not compete with it.

## Content boundary

Descriptions and links come from public GitHub repositories. Claims about personality and working style are positioning, not biographical facts. No private contact details, testimonials, customer claims, or invented metrics are shown.
